# GAME_WHAT_IS_A_NUMBER

> [!NOTE] 
> Project completed during the learning process. User: Kompocik1
> who also contributed to the code


This program is written in high-level C++. This game is easy. First, you guess a number from 1 to 100, and you have 6 chances to hit the correct number. If the guessed number is too high, the program prints "wylosowana liczba jest mniejsza niż twoja". If the guessed number is too low, the program prints "wylosowana liczba jest większa niż twoja".
If you win the first round, you go to round 2, where you have 7 chances to guess a number from 1 to 200. If you run out of chances, the program prints "niestety nie udało się".
If you win the second round, you go to round 3 with 8 chances, but you have to guess a number from 1 to 300. Be careful! In round 3, there is a randomly generated trap number—if you guess this number, you lose instantly.
